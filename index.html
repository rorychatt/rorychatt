open-apple-models

SpaceCorps/open-apple-models

Real tool calling for Apple's on-device Foundation Models — NPC dialogue, AI decisions and content generation for games on iOS, iPadOS, macOS and visionOS 27, with no API keys or server costs.

Measured the platform first: Apple's own fm serve returned 0 tool calls in 54 requests. Then built per-step tool steering, a Swift package, the oam CLI, an OpenAI-compatible server and a JSON-RPC protocol with a C ABI for game engines.

25 commitsSwift2026
14

open-android-models

SpaceCorps/open-android-models

The Android sibling on Gemini Nano via ML Kit's GenAI Prompt API. Same concepts and same JSON-RPC protocol, so a game engine can inject either backend per platform.

Gemini Nano has no native tool calling yet, so I built a validated step-envelope tool loop in Kotlin, plus a JNI entry point for native engines. Pre-release: tested on the JVM and against Apple's model as a proxy, not yet on a Gemini Nano device.

24 commitsKotlin2026
